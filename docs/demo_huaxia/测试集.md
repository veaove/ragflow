## 三、演示话术备注
- 第 1、3、5 这类「口语化 + 错别字」问法，是用来展示：即使客户不会规范提问，检索也能命中——这正是相似问/检索增强的价值。
- 在「检索测试」页可以看到命中的分块内容、相似度分数；改了相似问或阈值后重跑，能直观看到命中变化，对应需求清单里的「模拟测试 / 批量测试 / 相似问智能辅助」。
- 若某条未命中，现场演示「补一个相似问 → 重跑命中」，非常有说服力。
