# 华夏基金智能客服 · 客户演示脚本（开箱即用功能篇）

> 对象：华夏基金金融科技部（甲方）
> 目的：用 RAGFlow 现成能力，演示「智能客服应用层」成熟度，对应需求清单中
> 判定为 **开箱即用 / 纯配置** 的 5 项功能。全程约 15–20 分钟。
> 叙事主线：**一条寒暄 → 一个业务问答（带引用溯源）→ 检索测试看命中 → 咨询日志看全量会话 → 系统日志看审计**。

---

## 0. 演示前准备（内部，客户不在场）
1. 已用 `seed_demo_data.py` 或 Web 导入预置好：寒暄库、基金FAQ库、对话助手「小夏」。
2. 确认两个知识库文档状态为「已解析」。
3. 打开两个浏览器标签备用：① 聊天页（和小夏对话）② 知识库「检索测试」页。
4. 桌面准备好 `测试集.md`，方便现场粘贴。

---

## 1. 寒暄知识库（小夏会聊天，不硬答业务）
**点哪**：聊天页 → 选择助手「华夏基金智能客服-小夏」
**说什么**：`你好呀` → `你叫什么` → `哈哈` → `拜拜`
**看什么**：
- 小夏用亲切话术回应，识别为寒暄而非业务问题。
- 后台逻辑：寒暄库独立知识库，命中即直接作答，不进入业务检索。
**讲解话术**：「客服机器人首先要会寒暄、有温度，这部分是独立知识库+检索路由，纯配置即可，不需要开发。」

---

## 2. 基金 FAQ + 引用溯源（核心：回答有依据）
**说什么**：`我想买基金怎么操作` → `赎回几天到账` → `申购费打几折`
**看什么**：
- 小夏给出准确答案，并在回答下方展示 **引用来源**（命中的知识点卡片，含出处文档）。
- 这个「引用溯源」正是甲方需求里的「AI 效果追踪 / 话术出处可查」。
**讲解话术**：「所有答案都带引用，坐席和客户都能看到依据，可审计、可追溯，不会出现凭空编造。」

---

## 3. 相似问 / 检索增强（客户口语化也能命中）
**现场演示**：在知识库「检索测试」页，粘贴 `测试集.md` 第 1 条 `刚发的工资想理财，在哪能买基金`
**看什么**：命中「基金怎么买」知识点，即使客户表述和知识库标准问完全不同。
**加戏（最有说服力）**：打开某个 FAQ 知识点编辑页 → 点「相似问」→ 添加 `工资想理财去哪买` → 回到检索测试重跑 → 命中。
**讲解话术**：「标准问下面可以挂多个相似问（系统也支持 LLM 辅助生成），客户怎么问都能命中，这正是相似问/同义词配置的价值。」

---

## 4. 模拟测试 / 批量测试（回归不漂移）
**点哪**：知识库 → 选「基金FAQ库」→ 「检索测试」页（或批量测试入口）
**做什么**：把 `测试集.md` 业务问答 1–15 条逐条或批量粘贴，查看命中率与相似度分数。
**讲解话术**：「甲方需求里的『模拟测试 / 自动化回归』——新增或拆分知识点后，用测试集自动跑，检查命中度和准确率是否漂移，防止改坏。RAGFlow 内置检索测试与评估数据集，开箱即用。」
> 注：本版 Go 的「评估/批量测试」Web 入口依赖的 API 仍在从 Python 迁移；
> 当前用稳定的「检索测试」页 + 测试集演示，效果一致。正式上线版本会补齐批量评估 UI。

---

## 5. 用户咨询日志（全量会话 + 客户评价）
**点哪**：左侧「会话」/「聊天」列表 → 刚才和小夏的对话
**看什么**：
- 每轮对话的客户问、机器人答、命中引用、以及 **点赞/点踩（客户评价）** 全部留痕。
- 字段对应甲方需求「客户id、咨询内容、时间、回答内容、客户评价」。
**讲解话术**：「所有咨询全程留痕，客户评价可采集，为后续质检、效果分析、知识库优化提供数据基础——这正是 AI 效果追踪的数据底座。」

---

## 6. 系统日志（操作与接口审计）
**点哪**：右上角头像 → 系统 / 管理 → 日志（接口调用、知识库操作、任务）
**看什么**：文档上传、解析、对话调用等均有记录。
**讲解话术**：「操作留痕、接口调用可审计，满足甲方对系统可监控、可回溯的要求。这部分也是开箱即用的。」

---

## 7. 收尾：给甲方的价值总结（1 分钟）
- 今天演示的 6 块（寒暄、FAQ+溯源、相似问、测试回归、咨询日志、系统日志）**全部基于 RAGFlow 原生能力，配置即上线**，不依赖定制开发。
- 这正好对应甲方「应用层成熟度、快速投产、代码可交付」的核心诉求。
- 需要共建/定制的部分（蓝凌同步连接器、报表、质检、业务参数、IVR 语音）我们可在此基础上二次开发，分工清晰。

---

## 附：现场答疑预案
- **问：能接我们蓝凌知识库吗？** → 能，RAGFlow 同步器支持 60+ 数据源（Confluence/Notion/REST API/DB 等）+ 定时增量；蓝凌若无现成连接器，我们按它的接口定制一个，工作量可控。
- **问：能分渠道给不同答案吗？** → 能，多渠道配置 + 元数据过滤，可让 APP/Web 各自命中不同知识范围。
- **问：代码能给我们吗？** → RAGFlow 是 Apache 2.0 开源，我们交付的代码甲方可持续维护，符合你们「防乙方出问题时可自维」的要求。
