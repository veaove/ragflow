#### A. 智能体版（2 分钟，就是客户要的那种）

- **菜单**：左侧「**智能体**」→ 找「**华小夏-IVR（按键菜单）**」（和夏管家推送在同一个列表）
- **直链**：`http://172.30.20.51/agents/d84989e4e3ca4d328bfa9a5525418ac9`
- 打开后点右上角**运行/试运行**，右侧聊天框会先出现**开场白菜单**（1~9 + 0）

依次做这 5 件事：

| 做什么 | 期望 | 在验什么 |
|---|---|---|
| 看开场白 | 「您好，欢迎致电华夏基金客户服务中心…1 客服电话与服务时间…0 重新听一遍菜单」 | 开场就报菜单 |

**语音怎么听**：每条回答（包括开场白）下面有个**喇叭图标**，点一下就把这段念出来
（首次约 2 秒合成，之后同一段有缓存，点击即响）。

> **一个必须知道的边界**：平台默认不会自动出声，喇叭要手点。要「一进来自动念菜单」，
> 需要给智能体运行面板加一个「自动朗读」开关（前端小改，约 30 行，要发版）—— 我还没动，
> 等你说要不要做。
> 另外**别把这个智能体发布上架**：分享页会把喇叭按钮隐藏（`showLoudspeaker={false}`），
> 一上架反而听不到声音了。

#### B. 本地模拟器（视觉稿，1 分钟）

平台没有 IVR 引擎，放音收号得由话务平台做，所以另给一份能看到「电话长什么样」的页面。

启动（别直接双击 html 就指望有声音，走 http 更稳）：

```bash
cd /d/ZOO/code/ragflow/docs/huaxia_kefu/ivr-demo
python -m http.server 8899
```

浏览器打开 `http://127.0.0.1:8899`，点右边绿色的「**拨号**」。

按这条路径走一遍，约 1 分钟：

| 按 | 会听到 | 在验什么 |
|---|---|---|
| 拨号 | 欢迎语 + 5 个选项（1 交易 / 2 账户净值 / 3 产品费率 / 9 人工 / 0 重听） | 一级菜单 |
| **1** | 基金交易：买入、赎回、定投 | 二级菜单 |
| **2** | 赎回 / 卖出的说法 | 二级菜单 |
| `*` | 回到基金交易 | 返回上一级 |
| **5** | 「抱歉，您输入的按键无效，请重新选择。」然后回本级 | 无效键不跳走、不挂机 |
| `*` `*` | 一路退回欢迎语 | 多层返回 |
| **9** | 「正在为您转接人工客服…」，按键全部变灰，播完**自动挂机** | 终点节点没有死循环 |
| 重拨 | 回到欢迎语、按键恢复、日志清空 | 状态复位 |

客户最在意的三个点，演示时重点说：

1. **按键能打断播报**：欢迎语没念完就按 1，会立刻切到下一级（真实话务系统的 barge-in）
2. **每层都留了出口**：9 个业务节点末尾都有「按 1 转智能客服」，那是唯一接回 RAGFlow 的地方
3. **右侧「流程节点」可点**：客户想看全貌，直接点节点名跳转，不用一层层按

> 这 16 段话是平台 TTS 预合成的（音色统一），放在 `docs/huaxia_kefu/ivr-demo/audio/`，
> 可单独双击听，也可整包交货务平台当放音素材。
> 改流程只改 `scripts/build_ivr_demo.py` 里的 `NODES`，重跑 `python scripts/build_ivr_demo.py`
> 就会重生成语音、页面并自检。

## 三、一键脚本（技术验证，11 条断言）

```bash
cd /d/ZOO/code/ragflow
export RF_BASE_URL=http://172.30.20.51
export RF_SECRET_KEY=<kvrocks ragflow:system:secret_key>
export RF_ACCESS_TOKEN=<user.access_token>

python scripts/huaxia_configure.py eval     # 检索回归，11 条
python scripts/huaxia_configure.py test     # 冒烟：客服问答 / 转人工智能体
python scripts/huaxia_configure.py status   # 现状快照
python scripts/build_ivr_demo.py --check    # IVR 流程自检（死链/死胡同/音频）
```

输出形如：

```
[PASS] 华夏基金哪年成立的    2.41s 排名=1 召回=5 term=0.0 vec=0.944  (相似问)
[PASS] 怎么申购基金        2.12s 排名=1 召回=5 term=0.0 vec=0.805  (同义词展开)
```

**判定标准：11/11 才算健康**。掉到 9 以下说明最近一次改动把东西弄坏了（改库、改阈值、改 prompt）。

> 看文本会得到假阴性（我第一版验证方法就栽在这上面，11 条全 FAIL 但实际是好的）。

## 五、五个容易误判的点

1. **在「智能体」里找华小夏，找不到是正常的** —— 它是「知识问答」里的应用。这两个菜单是不同的东西。
2. **相似问命中了但排名不是第一** —— 「客服电话多少」排第 3，属正常。top_n=5 都能进 prompt，
   只要目标在这 5 条里就算过。别拿"必须第一"当标准。
3. **点喇叭要等约 2 秒** —— 不是坏了，是实时合成。见第 2 站说明。
4. **用接口测质检永远不触发** —— 质检走前端，必须在对话页里说话。
5. **智能体 `release=false` 仍然能试运行** —— release 只管对外发布，不管内部预览。

## 六、如果测出问题

按这个顺序自查：

| 现象 | 先看什么 |
|---|---|
| 答非所问 | 知识库 `language` 是不是 Chinese；应用阈值是不是被改高 |
| 口语问法召回不到 | 该标准问有没有挂相似问；跑 `eval` 看哪条 FAIL |
| 回答「抱歉，知识库中未找到」 | 阈值太高或 top_n 太小；也可能这条知识库里确实没有 |
| 质检不弹 | 是否在对话页（不是接口）；规则是否被「选用规则」取消掉 |
| 报表没数据 | 看明细页有没有该 session；沙箱应用的记录也会混在里面 |
| 卡片列表里找不到应用 | 是否用 `123456789@qq.com` 登录；应用是 `permission=me`，别人看不到 |
