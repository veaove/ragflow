## 一、五分钟最快路径（界面点，不用命令行）

### 第 1 站：生产问答 — `/chat/db888754c17946cbbc168d5408a13a58`

依次问这 4 句，**别问书面问法，要问客户真会说的话**：

| 问 | 期望 | 在验什么 |
|---|---|---|
| 在吗 | 「在的，我一直都在。请问您是想咨询基金购买、赎回、净值查询，还是其他业务呢？」 | 寒暄库命中（混库时这里会答成不相干内容） |
| 华夏基金哪年成立的 | 1998 年 4 月 9 日 | **相似问**（标准问是「什么时候成立的」，库里没有「哪年」两个字） |
| 客服电话多少 | 400-818-6666 / 010-50919000 | **相似问** |
| 你们的服务电话是多少 | 同上 | **同义词**（服务电话→客服电话） |

最后看回答气泡上有没有「引用/参考来源」，点开应能看到命中的 FAQ 条目。

### 第 2 站：IVR 播报 — `/chat/81a9368de6e64b03810f6679746bc76f`

问「客服电话是多少」，看回答是否满足**语音播报**的四个条件：

- 只有一段话，没有 1. 2. 3.、没有 **加粗**、没有表格
- 没有 `[ID:xxx]` 引用标号
- **60 字以内**
- 数字是朗读写法：「四零零八幺八六六六六」而不是「400-818-6666」

然后点回答下面的**喇叭图标**听声音（合成约 2 秒，先转圈再播）。已生成的音频样本在
`docs/huaxia_kefu/audio/` 下，可以直接听。

> 为什么点喇叭要等 2 秒：`tts=true` 本意是让后端预先把音频随消息返回，实测 `audio_binary`
> 返回 null（异步预合成没赶上 SSE），前端自动回退到「实时请求合成」。**功能不受影响**，
> 只是不"秒播"。这一点已记进 v2 文档的已知缺口。

### 第 3 站：转人工 — 智能体 `/agents`，找「夏管家推送」→ 试运行

| 问 | 期望 |
|---|---|
| 我要人工 | 「您好，已为您转接夏管家人工客服，请扫码联系：…」（二维码现在是占位图，会破图） |
| 基金定投起点金额 | 正常作答，100 元起、上限 20 万，带引用 |

> 该智能体 `release=false`（未对外发布），**不影响试运行**。等客户给真二维码才上架。

### 第 4 站：报表 — `/analytics/stats`

能看到咨询量、平均轮次、好评率、按应用分列、按天趋势。刚测的对话会立刻出现在
`/analytics/consultations` 里。

| # | 需求 | 在哪看 | 怎么算通过 |
|---|---|---|---|

| 4 | 咨询日志报表 | `/analytics/stats` + `/analytics/consultations` | 有量、有率、能按应用分；**响应速度为空是已知缺口** |
| 5 | 夏管家推广 | `/agents` → 夏管家推送 | 见第 3 站；二维码待客户素材 |
| 6 | 效果追踪 | `/studio` 或智能体运行记录 | 能看到每个节点的输入/输出/耗时 |
| 7 | 模拟测试 | `/chat/a958e5089ea54e668c4bdf465695bfce` | 沙箱应用能答，且绑的是「FAQ话术-沙箱」库 |
| 8 | 实时质检 | `/qc` → 规则列表 | 共 9 条，其中 4 条是本次新增的金融合规规则；生产应用选用 6 条 |
| 9 | 参数管理 | 看 v2 文档 3.1 的基线表 | 无独立参数页，参数固化在应用配置里 |
| 10 | 相似问智能辅助 | 知识库 → 变更集 → 生成相似问 | 能生成待确认的相似问，人工确认后入库 |
| 11 | IVR | 第 2 站 | 只有问答一环，无 IVR 引擎 |
| 12 | 批量测试 | 不做 | 替代方案见第四节 |
| 13 | 系统日志 | 控制台审计 | 库/应用/成员的操作都有留痕 |

**质检怎么测才触发**：质检是**前端 WebSocket 实时校验**，在对话页里才会弹提示。
故意问一句「你们能保证收益吗」应弹「QC-收益承诺-提示合规」；说「我要投诉」应弹「QC-投诉-提示转人工」。
用 API 直接调 `/chat/completions` **不会**触发 —— 别用接口测这项。

## 三、一键脚本（技术验证，11 条断言）

```bash
cd /d/ZOO/code/ragflow
export RF_BASE_URL=http://172.30.20.51
export RF_SECRET_KEY=<kvrocks ragflow:system:secret_key>
export RF_ACCESS_TOKEN=<user.access_token>

python scripts/huaxia_configure.py eval     # 检索回归，11 条
python scripts/huaxia_configure.py test     # 冒烟：客服/IVR/智能体各跑一遍
python scripts/huaxia_configure.py status   # 现状快照
```

`eval` 输出形如：

```
[PASS] 华夏基金哪年成立的    2.41s 排名=1 召回=5 term=0.0 vec=0.944  (相似问)
[PASS] 怎么申购基金        2.12s 排名=1 召回=5 term=0.0 vec=0.805  (同义词展开)
...
11/11 通过
```

**判定标准：11/11 才算健康**。掉到 9 以下说明最近一次改动（改库、改阈值、改 prompt）坏了东西。

> 这 11 条是**检索层面**的断言，直接看召回排序，不看回答文本 —— 因为模型有时不输出
> `[ID:x]` 标号，看文本会得到假阴性（我第一版验证方法就栽在这上面）。

## 四、给客户演示的 8 分钟脚本

1. **开场**（30 秒）：打开 `/chat/db888754…`，问「在吗」→ 展示闲聊与业务分流
2. **相似问**（1 分钟）：问「华夏基金哪年成立的」「客服电话多少」→
   强调「库里存的是书面标准问，客户口语也能命中，靠的是相似问」
3. **同义词**（1 分钟）：问「怎么申购基金」「你们的服务电话是多少」→ 展示别名归一
4. **质检**（1 分钟）：问「你们能保证收益吗」→ 弹合规提示，说明「只提示不拦截」
5. **IVR**（2 分钟）：切到 `/chat/81a9368d…` 问「客服电话是多少」→ 点喇叭放音，
   说明「同一套知识，语音渠道自动转成口语短句和中文读法」
6. **转人工**（1 分钟）：`/agents` → 夏管家推送试运行，说「我要人工」→ 推二维码
   （**demo 前务必先拿到真二维码替换 `xxxx`**）
7. **报表与沙箱**（1 分钟）：`/analytics/stats` 看刚才的对话已进报表；
   说明「改知识先过沙箱，验证过再上生产」

## 五、五个容易误判的点

1. **相似问命中了但排名不是 1** —— 「客服电话多少」排第 3，属正常。top_n=5 都能进 prompt，
   只要目标在这 5 条里就算过。别拿"必须第一"当标准。
2. **点喇叭要等约 2 秒** —— 不是坏了，是实时合成。见第 2 站说明。
3. **用接口测质检永远不触发** —— 质检走前端 WebSocket，必须在对话页里说话。
4. **智能体 `release=false` 仍然能试运行** —— release 只管对外发布，不管内部预览。
5. **换个账号登录看不到这些配置** —— 全部建在华夏基金租户（`123456789@qq.com`）下，
   且 `permission=me`。用超管或和君纵达账号看不到。

## 六、如果测出问题

按这个顺序自查：

| 现象 | 先看什么 |
|---|---|
| 答非所问 | 知识库 `language` 是不是 Chinese；应用 `similarity_threshold` 是不是被改高 |
| 口语问法召回不到 | 该标准问有没有挂相似问；跑了 `eval` 看哪条 FAIL |
| 回答里出现「抱歉，知识库中未找到」 | 阈值太高或 top_n 太小；也可能是这条知识库里确实没有 |
| 质检不弹 | 是否在对话页（不是接口）；规则是否被 `PUT /qc/rules/selection` 取消掉 |
| 报表没数据 | 看 `/analytics/consultations` 有无该 session；沙箱应用的记录也在里面 |
