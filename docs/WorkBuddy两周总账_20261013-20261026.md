## 6. 反复踩到的坑（这半个月最值钱的部分）

1. **版本号对 ≠ 部署对**：`/system/version` 是运行时 `git describe`，代码变了不重启也显示新版本，但二进制可能还是旧的。验证必须 `strings <binary> | grep <新提交特有串>`。
2. **`build.sh --all` 不可替代**：手写 `go build` 缺 `office_oxide.h`；且必须 `setsid nohup ... </dev/null &`，SSH 断连 SIGHUP 会删掉二进制但 systemd 仍 active。
3. **新增列不会自动加**：`AutoMigrate` 不含 knowledgebase 等表的后续列，必须显式 ensure 或跑 `--migrate`。
4. **`user_tenant.role` 与 `role_id` 是两套模型**：控制台编辑成员只写 `role_id`，邀请才写枚举；权限引擎默认读枚举 → 「界面上是部门管理员，实际没权限」。
5. **`tenant.GetInfoByUserID` 把 `role='owner'` 写死在 SQL**：被邀请的普通成员查不到租户 → 每个非 owner 一进首页就报 `102 Tenant not found!`。只读路径要改用 `dao.GetReadableInfoByUserID`。
6. **`requireOwnedTenantID` 类写法是权限陷阱**：取「用户第一个 owner 租户」会让「KB 所属租户的普通成员」全挂。资源鉴权统一走 `permission.CheckResource`。
7. **CRLF 假改动**：`core.autocrlf=true` 下 `git status` 报一堆 M，三方 hash 一致即说明已在 HEAD，直接 `git checkout --`。
8. **gofmt 别用 `-w`**：CRLF 会刷成 LF 产生巨型 diff，用 `gofmt f | tr -d '\r'` 比对。
9. **umi-request `code != 0` 不抛异常**：页面拿到 `{code,message,data:undefined}`，写 `?? []` 会把失败伪装成空列表。
10. **静态资源缺失必须 404**：SPA 兜底会让缺 `.js` 返回 200+html，页面白屏但网络面板全绿。
11. **`systemctl reload nginx` 会因 `/run/nginx.pid` 为 0 字节失败**：`echo <master_pid> > /run/nginx.pid` 后恢复。
12. **多会话共用一个工作区**：本地绝不 `git reset --hard`（会连别人未提交的改动一起丢），只 add 自己的文件，改完立刻 commit+push。
