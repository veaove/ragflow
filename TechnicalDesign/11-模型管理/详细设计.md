# 模型管理 - 详细设计

## 1. 模块概述

模型管理模块负责 LLM 提供商、模型实例、模型的统一管理与调度，支持对话、嵌入、重排、语音识别、语音合成、图像理解等 6 类模型，覆盖 80+ 提供商。

## 2. 模型类型体系

### 2.1 模型接口层次

**文件**: `internal/entity/models/`

```
ModelDriver (基础接口)
    ├── ChatModel        → Chat / Stream / Tool Calling
    ├── EmbeddingModel   → Embed
    ├── RerankModel      → Rerank
    ├── ASRModel         → Transcribe
    ├── TTSModel         → Speech
    └── ImageModel       → Generate / Understand
```

### 2.2 模型类型

**文件**: `internal/entity/models/types.go`

| 模型类型 | 用途 | 关键方法 |
|---------|------|---------|
| ChatModel | 对话生成 | Chat, Stream, WithTools |
| EmbeddingModel | 文本向量化 | Embed |
| RerankModel | 重排序 | Rerank |
| ASRModel | 语音转文字 | Transcribe |
| TTSModel | 文字转语音 | Speech |
| ImageModel | 图像生成/理解 | Generate, Understand |

### 2.3 EinoChatModel

**文件**: `internal/entity/models/llm.go`

封装 Eino 框架的 ChatModel，支持：
- 流式输出
- 工具调用（Tool Calling）
- 故障转移链（Failover）
- 推理内容（reasoning_content）分离

## 4. 模型工厂

### 4.1 ModelFactory

**文件**: `internal/service/model_factory.go`

```go
type ModelFactory struct {
    tenantDAO        *dao.TenantDAO
    modelProviderDAO *dao.TenantModelProviderDAO
    modelInstanceDAO *dao.TenantModelInstanceDAO
    modelDAO         *dao.TenantModelDAO

// 构造各类模型
func (f *ModelFactory) NewChatModel(ctx, access ModelAccess, modelRef string) (*models.ChatModel, error)
func (f *ModelFactory) NewEmbeddingModel(ctx, access ModelAccess, modelRef string) (*models.EmbeddingModel, error)
func (f *ModelFactory) NewRerankModel(ctx, access ModelAccess, modelRef string) (*models.RerankModel, error)

func (f *ModelFactory) NewDefaultEmbeddingModel(ctx, access) (*models.EmbeddingModel, error)
```

### 4.2 ModelAccess

```go
type ModelAccess struct {
    UserID   string
    TenantID string
}
```

### 4.3 modelTarget（内部解析结果）

```go
type modelTarget struct {
    ModelID       string
    ModelName     string
    ModelType     entity.ModelType
    ProviderName  string
    InstanceID    string
    InstanceName  string
    Driver        models.ModelDriver
    APIConfig     *models.APIConfig
    ModelInfo     *models.Model
    ContextLength int
    MaxOutput     int
    SupportsTools bool
}
```

### 4.4 模型解析流程

```
modelRef (如 "tenant-xxx/openai/gpt-4")
    │
    ▼
resolveConfig():
    1. 解析 provider / instance / model
    2. 查询 TenantModelProvider 获取配置
    3. 查询 TenantModelInstance 获取 API Key / 端点
    4. 查询 TenantModel 获取模型参数
    5. 校验租户权限
    6. 构造 modelTarget
    │
    ▼
构造具体模型实例（ChatModel / EmbeddingModel / ...）
```

**文件**: `internal/entity/tenant_model.go`

| 字段 | 说明 |
|------|------|
| ID | 模型 ID |
| InstanceID | 所属实例 |
| ModelName | 模型名称 |

### 5.4 关系链

```
Tenant
  └─ TenantModelProvider (提供商配置)
       └─ TenantModelInstance (实例: API Key + 端点)
            └─ TenantModel (具体模型: 名称 + 类型 + 参数)
```

## 9. 关键技术点

1. **三级模型管理**：Provider → Instance → Model，灵活配置
2. **80+ 提供商**：覆盖主流 LLM 服务商
3. **6 类模型**：Chat/Embedding/Rerank/ASR/TTS/Image
4. **统一工厂**：ModelFactory 屏蔽提供商差异
5. **故障转移**：EinoChatModel 支持 failover 链
6. **API Key 加密**：敏感凭证加密存储
7. **模型引用解析**：`tenant/provider/instance/model` 格式灵活引用
