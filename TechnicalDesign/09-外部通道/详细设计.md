# 外部通道 - 详细设计

## 1. 模块概述

外部通道模块将 RAGFlow 的对话能力接入第三方 IM 平台，使用户可通过钉钉、飞书、企业微信、Telegram 等渠道与 RAGFlow 对话。

## 2. 核心抽象

### 2.1 Channel 接口

**文件**: `internal/channels/core/channel.go`

```go
type Channel interface {
    ChannelID() string
    AccountID() string
    SetMessageHandler(handler MessageHandler)
    Start(ctx) error
    Stop() error

```


## 4. 通道运行时

### 4.1 Runtime

**文件**: `internal/channels/bootstrap.go`

```go
type Runtime struct {
    mu      sync.Mutex
    running map[string]runningChannel  // fingerprint → channel
    failed  map[string]failedChannel   // fingerprint → 失败信息
}

type runningChannel struct {
    channel     core.Channel
    fingerprint string
}

type failedChannel struct {
    fingerprint string
    attempts    int
    nextRetryAt time.Time
}
```

### 4.2 Reconcile 机制

通道运行时通过 Reconcile 循环动态管理通道实例：

```go
func Start(ctx) (*Runtime, error) {
    runtime := NewRuntime()
    // 首次同步
    runtime.Reconcile(ctx)
    // 后台循环
    go runtime.Run(ctx)
    return runtime, nil
}
```

**Reconcile 流程**：
```
定期（10s）扫描 DB 中的 ChatChannel 配置
    │
    ├─ 新增配置 → 启动 Channel 实例
    ├─ 配置变更 → 停止旧实例 → 启动新实例
    ├─ 配置删除 → 停止实例
    └─ 启动失败 → 指数退避重试（最长 5min）
```

### 4.3 失败重试

```go
const (
    reconcileInterval      = 10 * time.Second
    initialStartRetryDelay = 10 * time.Second
    maxStartRetryDelay     = 5 * time.Minute
)
```

## 5. 消息流转

```
第三方平台用户发送消息
        │
        ▼
Channel.Start() 监听
        │
        ▼
MessageHandler(ctx, IncomingMessage)
        │
        ▼
ChatChannelService 路由到对应对话
        │
        ▼
ChatPipelineService 执行 RAG 问答
        │
        ▼
Channel.Send(ctx, OutgoingMessage)
        │
        ▼
第三方平台返回回答
```

## 9. 关键技术点

1. **统一抽象**：Channel 接口屏蔽各平台差异
2. **动态管理**：Reconcile 循环自动同步配置变更
3. **失败重试**：指数退避避免频繁重启
4. **指纹去重**：通过 fingerprint 识别配置变更，避免无谓重启
5. **双向消息**：支持接收用户消息与主动推送回答
6. **多租户隔离**：通道配置按租户隔离
