# MCP 集成 - 详细设计

## 1. 模块概述

MCP（Model Context Protocol）集成模块提供双向 MCP 能力：
1. **对外暴露**：将 RAGFlow 的检索、知识库、对话能力作为 MCP 工具暴露给外部 AI 客户端
2. **对内消费**：管理和调用用户配置的外部 MCP 服务器，扩展 Agent 工具集

## 2. 核心数据模型

### 2.1 MCPServer（MCP 服务器配置）

**文件**: `internal/entity/mcp.go` → 表 `mcp_server`

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | string | 主键 |
| TenantID | string | 所属租户 |
| Name | string | 服务器名称 |
| Transport | string | 传输方式：stdio / http / sse |
| Config | JSONMap | 连接配置（命令、参数、URL 等） |
| Status | string | 状态 |

### 2.2 MCP 工具定义

**文件**: `internal/mcp/tools.json`（embed）

定义 RAGFlow 对外暴露的 MCP 工具 schema。

## 3. 对外 MCP 服务

### 3.1 MCP Server

**文件**: `internal/mcp/server.go`

将 RAGFlow 能力封装为 MCP 工具，通过 `/api/v1/mcp` 端点对外提供 JSON-RPC 服务。

#### Connector 接口

```go
type Connector interface {
    ListDatasets(ctx, page, pageSize, orderBy, ascending string) (string, error)
    ListChats(ctx, page, pageSize, orderBy, ascending string) (string, error)
    Retrieval(ctx, RetrievalRequest) (string, error)
}
```

#### 暴露的 MCP 工具

| 工具名 | 说明 |
|--------|------|
| `ragflow_retrieval` | 知识库检索 |
| `ragflow_list_datasets` | 列出知识库 |
| `ragflow_list_chats` | 列出对话 |

#### RetrievalRequest

```go
type RetrievalRequest struct {
    DatasetIDs             []string `json:"dataset_ids"`
    DocumentIDs            []string `json:"document_ids"`
    Question               string   `json:"question"`
    Page                   int      `json:"page"`
    PageSize               int      `json:"page_size"`
    SimilarityThreshold    float64  `json:"similarity_threshold"`
    VectorSimilarityWeight float64  `json:"vector_similarity_weight"`
    TopK                   int      `json:"top_k"`
    RerankID               string   `json:"rerank_id,omitempty"`
    Keyword                bool     `json:"keyword"`
    ForceRefresh           bool     `json:"force_refresh"`
}
```

### 3.2 服务启动

```go
func newServer(ctx, connector Connector) *sdk.Server {
    server := sdk.NewServer(
        &sdk.Implementation{Name: "ragflow-mcp-server", Version: "1.0.0"},
        &sdk.ServerOptions{
            Capabilities: &sdk.ServerCapabilities{Tools: &sdk.ToolCapabilities{}},
            SupportedProtocolVersions: []string{"2025-11-25", "2025-06-18", "2025-03-26", "2024-11-05"},
        },
    )
    // 注册 3 个工具
    sdk.AddTool(server, tools[0], retrievalHandler)
    sdk.AddTool(server, tools[1], listDatasetsHandler)
    sdk.AddTool(server, tools[2], listChatsHandler)
    return server
}
```

### 3.3 中间件增强

```go
server.AddReceivingMiddleware(func(next sdk.MethodHandler) sdk.MethodHandler {
    return func(ctx, method, req) (sdk.Result, error) {
        // tools/list 时动态增强工具描述（注入知识库列表）
        if method == "tools/list" {
            datasets, _ := connector.ListDatasets(ctx, 1, -1, ...)
            // 更新 retrieval 工具的 dataset_ids 描述
        }
        return next(ctx, method, req)
    }
})
```

## 5. Agent 中使用 MCP 工具

MCP 工具可在 Agent Canvas 中通过 Tool 组件调用：
- `internal/agent/tool/mcp.go` 提供 MCP 工具适配器
- 将外部 MCP 服务器的工具注册到 Agent 工具注册表
- Agent 运行时可调用这些外部工具

## 7. 关键技术点

1. **双向集成**：既是 MCP Server（对外暴露能力），也是 MCP Client（消费外部工具）
2. **多传输支持**：stdio / HTTP / SSE
3. **动态工具描述**：tools/list 时注入租户知识库列表，提升工具可用性
4. **协议版本兼容**：支持多个 MCP 协议版本
5. **Agent 集成**：外部 MCP 工具可无缝接入 Agent 画布
