# 智能体（Agent）- 详细设计

## 1. 模块概述

智能体模块是 RagFlow 的核心编排能力，提供可视化 Canvas 画布编排、组件化执行、工具调用与沙箱运行时。支持 Agent、Chatflow、Workflow 三种形态。

### 2.2 Canvas DSL 结构

**文件**: `internal/agent/canvas/canvas.go`

```go
type Canvas struct {
    Components map[string]CanvasComponent  // 节点 ID → 组件
    Path       []string                    // 执行路径
    History    []map[string]any            // 对话历史
    Memory     []map[string]any            // 记忆
    Retrieval  map[string]any              // 检索配置
    Globals    map[string]any              // 全局变量
    NodeParents map[string]string          // 节点分组（Loop/Parallel body）
}

type CanvasComponent struct {
    Obj         CanvasComponentObj
    Downstream  []string  // 下游节点
    Upstream    []string  // 上游节点
    DisplayName string    // 显示名
}

type CanvasComponentObj struct {
    ComponentName string         // 组件名（LLM/Retrieval/...）
    Params        map[string]any // 组件参数
}
```

## 7. Agent 执行流程

```
用户触发画布运行
    │
    ▼
1. 加载 UserCanvas.DSL
    │
    ▼
2. Canvas.Compile() → Eino Workflow
    ├─ 解析 Components
    ├─ 校验 DSL 结构
    ├─ 构建节点依赖图
    └─ 编译为 compose.Runnable
    │
    ▼
3. Scheduler 调度执行
    ├─ 从 Begin 节点开始
    ├─ 拓扑排序确定顺序
    ├─ 逐个 Component.Invoke(ctx, db, inputs)
    ├─ 变量通过 CanvasState 传递
    ├─ 支持 Loop / Parallel / Switch
    └─ 工具调用通过 Tool 组件分发
    │
    ▼
4. End 节点输出结果
    │
    ▼
5. 运行记录持久化（AgentRun）
    │
    ▼
6. 返回 RunEvent 流（SSE）
```

## 11. 关键技术点

1. **DSL 驱动编排**：JSON DSL 描述画布，可视化编辑
2. **Eino 框架集成**：编译为 Eino Workflow 执行
3. **组件化设计**：30+ 组件，可扩展
4. **工具生态**：40+ 内置工具 + MCP 外部工具
5. **沙箱隔离**：代码执行环境隔离，安全可控
6. **流式输出**：SSE 实时推送执行事件
7. **运行追踪**：CheckPointStore + RunTracker 支持断点续跑
8. **多形态支持**：Agent / Chatflow / Workflow / Dataflow
