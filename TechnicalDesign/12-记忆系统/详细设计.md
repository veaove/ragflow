# 记忆系统 - 详细设计

## 1. 模块概述

记忆系统为 RAGFlow 提供跨会话的长期记忆能力，支持从对话中自动提取结构化记忆、记忆检索与上下文注入，使 Agent 和对话具备"记住"用户偏好与历史事实的能力。

## 2. 核心数据模型

### 2.1 Memory（记忆存储）

**文件**: `internal/entity/memory.go`

| 字段 | 说明 |
|------|------|
| ID | 记忆 ID |
| TenantID | 所属租户 |
| UserID | 所属用户 |
| Name | 记忆名称 |
| Config | 记忆配置（提取规则、模型等） |
| Status | 状态 |

### 2.2 MemoryMessage（记忆消息）

**文件**: `internal/entity/memory.go`

| 字段 | 说明 |
|------|------|
| ID | 消息 ID |
| MemoryID | 所属记忆 |
| Role | 角色（user/assistant） |
| Content | 消息内容 |
| Metadata | 元数据 |
| CreateTime | 创建时间 |

### 2.3 MemoryTask（记忆提取任务）

**文件**: `internal/entity/memory_task.go`

后台异步提取记忆的任务记录。

## 3. 核心服务

### 3.1 MemoryService

**文件**: `internal/service/memory.go`

```go
type MemoryService struct {
    memoryDAO *dao.MemoryDAO
}

// 记忆 CRUD
func (s *MemoryService) CreateMemory(ctx, req) (*Memory, error)
func (s *MemoryService) UpdateMemory(id, req) error
func (s *MemoryService) DeleteMemory(id) error
func (s *MemoryService) ListMemories(userID) ([]Memory, error)
func (s *MemoryService) GetMemoryConfig(id) (*MemoryConfig, error)

// 消息管理
func (s *MemoryService) GetMemoryMessages(memoryID) ([]MemoryMessage, error)
func (s *MemoryService) AddMessage(memoryID, role, content) error
func (s *MemoryService) UpdateMessage(messageID, content) error
func (s *MemoryService) ForgetMessage(messageID) error
func (s *MemoryService) SearchMessage(query) ([]MemoryMessage, error)
```

### 3.2 MemoryExtractor

**文件**: `internal/service/memory_extractor.go`

从对话消息中提取结构化记忆：

```go
type MemoryExtractor struct {
    modelFactory *ModelFactory
}

func (e *MemoryExtractor) Extract(ctx, messages) ([]MemoryFact, error)
```

**提取流程**：
1. 将对话历史发送给 LLM
2. LLM 提取关键事实、用户偏好等
3. 结构化输出为 MemoryFact 列表
4. 去重与合并后存储

### 3.3 MemoryMessageService

**文件**: `internal/service/memory_message_service.go`

管理记忆消息的增删改查与搜索。

### 3.4 MemoryReconciler

**文件**: `internal/service/memory_reconciler.go`

后台异步处理记忆提取任务：
- 扫描待处理的 MemoryTask
- 调用 MemoryExtractor 提取
- 写入 MemoryMessage
- 标记任务完成

## 4. 记忆在对话中的应用

### 4.1 MemorySaverAdapter

**文件**: `internal/service/memory_saver_adapter.go`

适配 Agent 画布的 MemorySave 组件，将对话轮次持久化到记忆存储。

### 4.2 记忆检索注入

对话时检索相关记忆并注入上下文：

```
用户问题
    │
    ▼
检索相关历史记忆（按语义相似度）
    │
    ▼
注入到 Prompt 上下文
    │
    ▼
LLM 生成回答（参考历史记忆）
```

## 6. 关键技术点

1. **异步提取**：记忆提取通过后台任务异步执行，不阻塞对话
2. **语义检索**：记忆搜索基于向量相似度
3. **Agent 集成**：MemorySave 组件可在画布中持久化对话
4. **上下文注入**：对话时自动检索相关记忆增强回答
5. **遗忘机制**：支持主动遗忘特定记忆
