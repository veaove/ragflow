# 连接器与同步 - 详细设计

## 1. 模块概述

连接器与同步模块负责从外部数据源（代码仓库、云盘、协作工具、数据库等）拉取数据并同步到 RAGFlow 知识库，支持定时增量同步与过期清理。

## 2. 核心架构

```
Syncer Process
┌──────────────────────────────────────────┐
│  Scheduler (定时调度)                      │
│      │                                    │
│      ▼                                    │
│  TaskWorker Pool                          │
│      │                                    │
│      ▼                                    │
│  TaskCoordinator                          │
│      ├─ SyncRunner (增量同步)              │
│      └─ PruneRunner (过期清理)             │
│              │                             │
│              ▼                             │
│  Connector (外部数据源)                    │
│      │                                    │
│      ▼                                    │
│  DocumentService (写入知识库)              │
└──────────────────────────────────────────┘
```

## 3. Syncer 主控

### 3.1 Syncer 结构

**文件**: `internal/syncer/syncer.go`

```go
type Syncer struct {
    id          string
    config      Config
    queue       chan TaskEnvelope
    scheduler   *Scheduler
    worker      *TaskWorker
    executor    *SyncJobExecutor
    cancel      context.CancelFunc
    workerGroup sync.WaitGroup
    ShutdownCh  chan struct{}
}
```

### 3.2 Config

**文件**: `internal/syncer/config.go`

```go
type Config struct {
    TaskWorkerCount    int           // worker 数量
    TaskQueueSize      int           // 队列大小
    MaxRetryCount      int           // 最大重试次数
    RetryDelay         time.Duration // 重试延迟
    MaxAnchorRestarts  int           // 最大锚点重启次数
}
```

### 3.3 生命周期

```go
func (s *Syncer) StartContext(ctx) error {
    s.scheduler.Run(ctx)   // 启动调度
    s.worker.Run(ctx)      // 启动 worker
}

func (s *Syncer) Stop() {
    s.cancel()
    s.workerGroup.Wait()
    s.executor.Close()
    close(s.ShutdownCh)
}
```

## 7. 同步流程

### 7.1 增量同步

**文件**: `internal/syncer/sync_runner.go`

```
1. 准备 checkpoint（上次同步位置）
2. OpenSync(session)
3. 循环:
   ├─ NextBatch() 拉取一批文档
   ├─ 提交 batch job（写入知识库）
   ├─ 处理 resume/restart
   └─ 更新 checkpoint
4. 完成同步，删除 checkpoint
```

### 7.2 错误恢复

```go
// 处理 ErrSyncResumeInvalid
if errors.Is(err, ErrSyncResumeInvalid) {
    // 在最大重启次数内 reset checkpoint 后重新打开 session
    if restartCount < maxRestarts {
        checkpoint = nil  // 重置，从头开始
        continue
    }
}
```

### 7.3 过期清理（Prune）

**文件**: `internal/syncer/prune_runner.go`

```
1. OpenPrune(session)
2. FetchSlimSnapshot() 获取外部完整文档列表
3. 对比知识库现有文档，找出已删除的
4. DeleteStale() 删除过期文档
5. 完成 prune
```

## 8. 任务协调器

**文件**: `internal/syncer/task_coordinator.go`

```go
func (c *TaskCoordinator) Execute(ctx, taskID string) error {
    // 1. 打开 connector
    // 2. 校验配置
    // 3. 按任务类型分派
    switch taskType {
    case TaskTypeSync:
        return c.syncRunner.Run(ctx, task, connector)
    case TaskTypePrune:
        return c.pruneRunner.Run(ctx, task, connector)
    }
}
```

## 12. 关键技术点

1. **增量同步**：通过 checkpoint 记录同步位置，只拉取变更数据
2. **Checkpoint 恢复**：同步失败可从 checkpoint 恢复，避免全量重拉
3. **过期清理**：PruneRunner 对比外部快照，删除已不存在的文档
4. **50+ 连接器**：覆盖主流 SaaS、数据库、存储、协作工具
5. **NATS 调度**：支持分布式多 Syncer 实例负载均衡
6. **指数退避重试**：同步失败自动重试
7. **配置校验**：创建连接器时校验配置有效性
