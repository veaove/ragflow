# 技能空间 - 详细设计

## 1. 模块概述

技能空间（Skill Space）模块提供技能（Skill）的组织、索引与检索能力，将知识库中的文档片段抽象为可复用的"技能"，支持技能树结构与语义搜索。

### 3.2 SkillIndexer

**文件**: `internal/service/skill_indexer.go`

技能索引服务：

```go
type SkillIndexer struct {
    docEngine engine.DocEngine
}

// 索引技能到文档引擎
func (i *SkillIndexer) IndexSkills(ctx, spaceID, skills) error
func (i *SkillIndexer) DeleteSkillIndex(ctx, spaceID) error
func (i *SkillIndexer) Reindex(ctx, spaceID) error
```

索引流程：
1. 从知识库提取技能相关 chunk
2. 生成技能文档（标题、描述、内容、标签）
3. 写入文档引擎（独立索引）
4. 支持增量更新与全量重建

## 4. 技能树结构

技能以树形结构组织：

```
技能空间
├── 分类 A
│   ├── 技能 1
│   └── 技能 2
├── 分类 B
│   └── 子分类
│       └── 技能 3
```

- `GetSkillTree` 返回完整树结构
- `ListNavigation` 返回导航节点
- `ListNavigationChildren` 返回子节点

## 5. 技能页面

每个技能可生成 Wiki 风格页面：
- 标题
- 描述
- 详细内容
- 相关技能
- 来源引用

## 7. 关键技术点

1. **独立索引**：技能索引与知识库 chunk 索引分离
2. **树形组织**：支持多层级技能分类
3. **语义搜索**：基于向量的技能检索
4. **Wiki 页面**：技能可生成为结构化页面
5. **增量索引**：支持增量更新与全量重建
