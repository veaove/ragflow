# 知识库管理 - 详细设计

## 1. 模块概述

知识库（Dataset / Knowledgebase）是 RAGFlow 的核心数据容器，管理文档集合、解析配置、元数据、标签、同义词与变更集。

## 2. 核心数据模型

### 2.1 Knowledgebase（知识库）

**文件**: `internal/entity/dataset.go` → 表 `knowledgebase`

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | string(32) | 主键 |
| TenantID | string | 所属租户 |
| Name | string(128) | 知识库名称 |
| Description | string | 描述 |
| Language | string | 语言（影响分词与索引） |
| EmbedID | string | 嵌入模型 |
| EmbedModelID | string | 嵌入模型实例 |
| Permission | string | me / team |
| ParserIDs | string | 可用解析器 |
| ChunkMethod | JSONMap | 分块方法配置 |
| MetadataConfig | JSONMap | 元数据字段配置 |
| Status | string(1) | 状态 |

### 2.2 DatasetTags（知识库标签）

关联知识库与标签，支持按标签聚合检索。

### 2.3 SynonymGroup（同义词组）

**文件**: `internal/entity/synonym.go`

| 字段 | 说明 |
|------|------|
| ID | 同义词组 ID |
| KbID | 所属知识库 |
| Words | JSON 数组，同义词列表 |
| Enabled | 是否启用 |

### 2.4 KBChangeSet（知识库变更集）

**文件**: `internal/entity/kb_change_set.go`

类 Git 的 staged-edit 工作流：
- 草稿状态：编辑 chunk 但不影响线上检索
- 支持检索对比（retrieval-compare）
- 支持相似问生成（similar-questions）
- 发布（publish）/ 丢弃（discard）

## 4. 知识库检索流程

```
POST /api/v1/datasets/:id/search
  → 解析查询参数（question, top_k, similarity_threshold, ...）
  → 构造 RetrievalRequest
  → 调用 RetrievalService.Retrieval:
      1. 查询理解：同义词扩展、关键词提取
      2. 向量检索（KNN）
      3. 关键词检索（BM25）
      4. 混合排序（vector_similarity_weight 加权）
      5. 重排序（Rerank 模型，可选）
      6. 元数据过滤
  → 返回 chunk 列表 + 相似度分数
```

## 5. 知识库图谱

`GET /api/v1/datasets/:id/graph`

基于文档引擎的聚合能力，返回知识库的知识图谱结构：
- 节点：实体、文档、chunk
- 边：实体关系、引用关系
- 用于前端可视化展示

## 7. 关键技术点

1. **多语言支持**：`language` 字段影响分词器选择与全文索引 analyzer
2. **元数据驱动检索**：动态元数据字段可参与检索过滤
3. **同义词热加载**：同义词组变更后通过 `QueryBuilder` 实时生效
4. **变更集隔离**：草稿 chunk 写入独立索引，发布时原子切换
5. **权限控制**：`permission=me/team` 控制知识库可见范围
